# Мой первый проект

Привет! Это мой первый репозиторий на GitHub.

## Что такое репозиторий

Репозиторий — это папка проекта, которая помнит каждое изменение:
кто, когда и что поменял. Любую старую версию можно посмотреть
или вернуть.

## Чему я здесь учусь

- создавать репозиторий;
- делать изменения в отдельной ветке;
- открывать Pull Request и смотреть, что изменилось;
- нажимать Merge, чтобы принять изменения.
